# Tutorials

Guided paths: step by step from nothing to a result. A tutorial explains
little and makes the choices for you. The *why* is in the
[explanation](../explanation/index.md), the *what* in the
[reference](../reference/index.md). For a specific task, use the
[how-to guides](../how-to/index.md).

- [Try it offline](10-try-it-offline.md): run the CLI against the built-in
  fake backend. No Odoo, no account, ten minutes.
- [Your first booking](20-first-booking.md): connect to your Odoo, find a
  project and book an entry.
- [A tour of the TUI](30-tui-tour.md): the weekly grid, the detail view, adding
  and editing entries, search and attendance.
