# odoo-work-cli

CLI for managing Odoo 17 timesheets

### Options

```
      --backend string   backend: odoo (default) or fake (offline, made-up data; env ODOO_WORK_CLI_BACKEND)
      --config string    config file path (skip discovery)
  -h, --help             help for odoo-work-cli
```
