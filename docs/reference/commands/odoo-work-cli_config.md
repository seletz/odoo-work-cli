# odoo-work-cli config

Show discovered config files and merged configuration

```
odoo-work-cli config [flags]
```

### Options

```
  -h, --help     help for config
      --merged   print merged TOML config (password redacted)
```

### Options inherited from parent commands

```
      --backend string   backend: odoo (default) or fake (offline, made-up data; env ODOO_WORK_CLI_BACKEND)
      --config string    config file path (skip discovery)
```
